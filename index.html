MFA enrollment is unavailable in this app. Firebase MFA requires Authentication with Identity Platform and verified email; project settings have not been checked.

Data Vault Controls

Aura stores transcript text, analysis references, journal entries, and practice sessions under the signed-in Firebase UID in this browser. This is localStorage, not a secure database.
